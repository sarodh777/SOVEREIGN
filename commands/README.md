# Commands folder

These scripts make it easier to start the backend and frontend.

## Run backend
Open PowerShell and run:

```powershell
cd .\commands
./run-backend.ps1
```

## Run frontend
Open PowerShell and run:

```powershell
cd .\commands
./run-frontend.ps1
```

## Run both in new terminals
Open PowerShell and run:

```powershell
cd .\commands
./run-all.ps1
```
